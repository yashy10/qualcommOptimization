Benson Edge: depth-pruned, three-epoch recovered, INT8 MobileNetV2.
Selected run: b3_kd_lr001_e3_int8.

Build from this source folder:
  pdflatex -interaction=nonstopmode -halt-on-error technical_report.tex
  pdflatex -interaction=nonstopmode -halt-on-error technical_report.tex
  pdflatex -interaction=nonstopmode -halt-on-error technical_report_2page.tex
  pdflatex -interaction=nonstopmode -halt-on-error technical_report_2page.tex

technical_report.tex includes the third-page dashboard appendix.
technical_report_2page.tex omits that appendix for the original two-page limit.
Keep tradeoff.pdf and dashboard_appendix.tex beside the main .tex files.

To refresh figures/tables from the repository results, from this folder:
  python3 generate_tradeoff.py --results ../../results
  python3 generate_dashboard_appendix.py --results ../../results
The figure generator needs matplotlib. Both generators default to ../results
when rebuilding from the submission folder. Static figure/table files are
included, so building the PDFs alone does not need Python or experiment data.

The appendix contains 16 full-dataset and 26 Stage A records. B3 three-epoch
INT8 is selected; Q3a and one-epoch B3 are historical comparisons. Final local
timing is provisional. Sizes use MiB (2^20 bytes). See metrics.json for timing
and AI Hub profile provenance. Recovery-excluded accuracy is FP32 only.
