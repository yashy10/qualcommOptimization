Build the three-page report (two-page paper plus dashboard appendix):

  pdflatex -interaction=nonstopmode -halt-on-error technical_report.tex
  pdflatex -interaction=nonstopmode -halt-on-error technical_report.tex

Keep tradeoff.pdf and dashboard_appendix.tex beside the main .tex file.
The existing two-page version can be rebuilt using technical_report_2page.tex.

The appendix is generated from results JSON and mirrors dashboard milestone
timing substitutions. It includes 14 full-dataset runs and 26 Stage A runs.
To refresh from the repository, run from submission/report_source:

  python3 generate_dashboard_appendix.py --results ../../results

Recompile the report afterward. To build the existing PDF from this source
bundle alone, the included appendix is sufficient; no experiment data is needed.

Q3a is the selected model. B3 timing is provisional. Sizes use MiB (2^20 bytes).
