{\small\textbf{Benson Edge}\quad\textbullet\quad Minimalist Edge AI Challenge\quad\textbullet\quad 13 October 2026}

\vspace{-5pt}
\noindent\textbf{Abstract.} We compress the supplied distilled MobileNetV2 through residual-block removal, teacher-assisted recovery, and static INT8 quantization. The selected B3 model removes blocks 6, 9 and 16, recovers for three epochs at learning rate 0.001, then applies per-channel, 99.99-percentile quantization. It achieves 98.84\% accuracy on the 27,000-image competition evaluation at 2.052 MiB. Compared with our previous quantization-only reference, it is 17.6\% smaller with a 0.08-percentage-point accuracy tradeoff and improved worst-class accuracy. We distinguish measured accuracy and size from provisional local timing.

\section{Task and evaluation protocol}
We classify EuroSAT RGB images into ten land-use classes. The model accepts FP32 input \code{input}, shape $(1,3,224,224)$, and returns ten scores. Preprocessing resizes images to 224, converts them to tensors, and applies ImageNet normalization. Export uses ONNX opset 13 with \code{dynamo=False}; inference uses ONNX Runtime 1.31.0 on CPU.

Per the recorded judge instruction, reported competition accuracy covers all 27,000 images, including recovery and calibration samples. A separate 21,600-image evaluation excludes recovery-training images, but is not an independent test of the supplied pretrained checkpoint. Local baseline values are our measurements, not organizer reference figures.

\section{Compression pipeline and design choices}
\noindent\textbf{Pipeline.} Supplied checkpoint $\rightarrow$ remove three residual blocks $\rightarrow$ adaptive BatchNorm $\rightarrow$ knowledge-distillation recovery $\rightarrow$ FP32 ONNX $\rightarrow$ graph preprocessing $\rightarrow$ recalibration $\rightarrow$ static INT8 QDQ.

\noindent\textbf{Pruning exploration.} We screened 26 Stage A records on 2,700 fixed images, disjoint from the 5,400 recovery images (seed 0). Width sweeps used Torch-Pruning 1.6.1, magnitude importance, global/isomorphic or uniform channel selection, multiples of eight, and a protected classifier. At 10\% global width pruning, accuracy fell from 99.37\% to 77.19\% without recovery. Alternative BN-scale and Taylor criteria did not rescue the 30\% setting.

Depth pruning was less damaging. Replacing residual blocks 6, 9 or 16 individually with Identity gave 98.96\%, 98.96\% and 98.93\%. Removing all three gave 97.56\%; four and five removals fell to 94.07\% and 91.07\%. Each candidate used adaptive BN (100 batches of 32). We selected the three-block structure; \textbf{the final model uses no width pruning}.

\noindent\textbf{Recovery.} The initial one-epoch CPU attempt at learning rate 0.005 achieved only 96.52\% after INT8. The selected run restarts from the three-block pruned model and uses the recipe below. Both learning rate and duration changed, so their individual effects are not isolated.

The loss combines $0.3\,\mathrm{CE}$ with $0.7T^2$ times teacher-to-student KL divergence. Epoch times exclude setup and evaluation. Quick-eval accuracy progressed through 97.41\%, 99.26\% and 99.22\%; the submitted model uses epoch three. Its pre-quantization accuracy on the recovery-excluded 80\% was 98.75\%.

\noindent\textbf{Quantization.} We run \code{quant\_pre\_process}, then static QDQ with signed INT8 weights and activations (S8S8), per-channel weight scales, percentile 99.99, and no excluded layers. Activation ranges are recalibrated on the recovered model using 300 fixed images (30/class, seed 42), rather than reused from the unpruned model~\cite{ort}.

The selected model is $4.15\times$ smaller than FP32, with 17.4\% fewer parameters and 12.3\% fewer MACs. Overall accuracy drops 0.32 percentage points. Against Q3a, it saves another 17.6\% of storage for 0.08 points of accuracy. Its weakest class is Pasture (97.70\%); PermanentCrop improves from 95.84\% in FP32 to 98.20\%. Compared with FP32, Highway and Residential fall by 1.64 and 1.43 points, respectively. Thus the gain in worst-class accuracy does not mean every class improves.

The recovered FP32 and INT8 models both score 98.84\% overall at reported precision. Quantization reduces the recovered model from 7.028 to 2.052 MiB with no rounded overall-accuracy loss. Selection favors the smaller, more balanced model despite being 0.06 points below the original 98.9\% planning target; this tradeoff is explicit.

\noindent\textbf{Local measurement limits.} Inference uses an 11-core M3 Pro with 18 GB RAM, batch one, and default ORT threads. The selected run used ten warm-ups and 100 timed inferences; background CPU was 48.4\%. A new five-round benchmark refused to start at 43\% CPU on battery. We therefore do not claim a verified local speedup over Q3a. Energy is a CodeCarbon CPU-load/TDP estimate over 15 seconds, not a power-sensor measurement.

\section{Qualcomm device profile}
We use the Dragonwing RB3 Gen 2 Vision Kit (QCS6490, Qualcomm Linux 1.6), selected after the project's catalog check found no UNO Q / QRB2210 profile. This is a listed Linux IoT proxy, not measured UNO Q performance. A new profile of the selected B3 reports \textbf{5.523 ms}, versus 26.690 ms for FP32 (4.83$\times$). Estimated peak memory is 27.06 MiB versus 28.10 MiB for FP32. Both profiles execute on CPU; no NPU acceleration is claimed. Compile/profile IDs are \code{jgn1kl6vp}/\code{jp2oe0kxg}. The older Q3a profile is retained only as a separate reference.

\section{Lessons and reproducibility}
The first recovery attempt showed that removing blocks alone was insufficient. The later three-epoch, lower-learning-rate run substantially recovered accuracy, and MPS reduced recorded training-loop time to 87 seconds. This is evidence for the combined recipe, not proof that either change alone caused the improvement. Width pruning, teacher-versus-label-only recovery, quantization-aware training and best-epoch selection remain opportunities for further controlled study.

The submitted ONNX file is byte-identical to the selected three-epoch B3 artifact, SHA-256 prefix \code{e80fd982b0ab1c8f}. Its graph has 43 convolutions and seven residual additions (versus 52 and ten before pruning), with 54 QuantizeLinear and 142 DequantizeLinear nodes. The saved checks confirm the required input/output shapes and absence of dynamic-quantization operators.

The source bundle includes fixed subset indices, pruning and recovery configurations, training/export code, quantization settings and raw results. Run \code{reproduce\_selected.sh} in a fresh workspace with the supplied student/teacher checkpoints and EuroSAT data; it performs pruning, teacher caching, recovery, export and quantization. The original run used MPS; CPU reproduction may differ numerically. \code{metrics.json} records the complete model hash and measurement provenance. The 98.75\% recovery-excluded score belongs to the FP32 recovered model; no separate INT8 score on that subset is claimed.
